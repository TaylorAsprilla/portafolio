## 📊 Próximos Pasos Recomendados

### 1. **Google Search Console**

```
1. Visitar: https://search.google.com/search-console
2. Agregar propiedad con tu dominio
3. Verificar propiedad
4. Enviar sitemap: https://tudominio.com/sitemap.xml
5. Copiar código de verificación
6. Pegar en layout.tsx donde dice "google-site-verification-code"
```

### 2. **Google Analytics (Opcional)**

```bash
# Instalar paquete
npm install @next/third-parties

# Agregar en layout.tsx
import { GoogleAnalytics } from '@next/third-parties/google'

// En el body
<GoogleAnalytics gaId="G-XXXXXXXXXX" />
```

### 3. **Crear Imagen OG Personalizada**

- Tamaño: 1200x630px
- Incluir: Logo, texto llamativo
- Guardar en: `public/og-image.png`
- Actualizar en layout.tsx

### 4. **Optimizar Imágenes**

- Usar WebP para mejor compresión
- Agregar alt text descriptivos
- Lazy loading (ya implementado con Next.js)

### 5. **Contenido SEO**
